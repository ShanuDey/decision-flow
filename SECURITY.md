# Security Policy

## Supported versions

Security fixes go to the latest release only.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately with the "Report a vulnerability" button on the
[Security tab](https://github.com/ShanuDey/decision-flow/security/advisories/new) of this repository.

Include:
- What you found and where (URL, file or endpoint)
- Steps to reproduce it
- The impact, if you know it

## What to expect

- A reply within 3 working days.
- An update when the problem is confirmed and when a fix is released.
- Credit in the release notes, if you want it.

## Scope

In scope: the app at https://decision-flow-live.vercel.app and the code in this repository.

Out of scope: denial of service by high traffic volume, and problems in third-party services the project depends on.

Please do not access other people's data, and stop testing once you have shown the problem exists.
