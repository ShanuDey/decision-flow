Stores a Groq API key and sends it as a bearer token, only to `api.groq.com`.

## Set up

1. Create an API key in the Groq console (the free tier does not ask for a card). It starts with `gsk_`.
2. Add a connection of this type and paste the key. It is stored encrypted and never shown again.
3. Set a default model, using an id from the Groq console such as `openai/gpt-oss-20b`. Templates for this type use it. Free models change, so copy the id from the console.
