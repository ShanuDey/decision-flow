Stores an OpenAI API key and sends it as a bearer token, only to `api.openai.com`.

## Set up

1. Create an API key in the OpenAI dashboard.
2. Add a connection of this type and paste the key. It is stored encrypted and never shown again.
3. Optionally set a default model, such as `gpt-4o-mini`. Templates for this type use it.

For another provider with an OpenAI-style API, use the built-in OpenAI-compatible type instead.
