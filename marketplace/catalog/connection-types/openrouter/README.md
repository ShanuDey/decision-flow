Stores an OpenRouter API key and sends it as a bearer token, only to `openrouter.ai`.

## Set up

1. Create an API key on OpenRouter.
2. Add a connection of this type and paste the key. It is stored encrypted and never shown again.
3. Optionally set a default model as `vendor/model`, such as `openai/gpt-4o-mini`. Templates for this type use it.
