Sends a text to an OpenAI chat model and returns `summary`, at most three sentences.

## Use

1. Install the flow. It installs the OpenAI connection type with it.
2. Create an OpenAI connection, then start a new flow from this one and match the connection when asked. The flow uses the connection's default model.
3. Run it with `text`.

To change the instructions, edit the system message in the **Summarize** node after you create your flow.
