Fills an HTTP Request node that opens an issue with `POST /repos/OWNER/REPO/issues`.

## Use

1. Install the template. It installs the GitHub connection type with it.
2. Add the template to a flow, then replace `OWNER` and `REPO` in the URL.
3. Choose a GitHub connection whose token can write issues on that repository.
4. Pass `title` and `body` as flow inputs.
